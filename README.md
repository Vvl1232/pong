# Pong Game
A simple Pong game built using Python's Turtle graphics library.

Features
Two Paddles:
Left Paddle: W (up), S (down)
Right Paddle: Up (up), Down (down)
Bouncing Ball: Speed increases during gameplay.
Scoreboard: Tracks and displays scores for both paddles.
Game Over Screen: Displays when the ball goes out of bounds.

How to Play
Controls:
Left Paddle: W (up), S (down)
Right Paddle: Up (up), Down (down)
Hit the ball with the paddle to score points.
Each paddle hit increases the respective player's score by 1.
Game ends when the ball goes out of bounds.
